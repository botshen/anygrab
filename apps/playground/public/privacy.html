Privacy Policy / 隐私政策

Effective Date / 生效日期: November 15, 2026 · Applies to AnyGrab Chrome Extension, CLI, MCP & Web Playground

English — Privacy Policy

1. Zero Data Collection Commitment

AnyGrab is a 100% local, open-source webpage DOM and UI context distillation tool licensed under the MIT License. AnyGrab does not collect, transmit, store on external servers, sell, rent, or share any personal data, browsing history, webpage content, cookies, credentials, IP addresses, or analytics telemetry.

2. Browser Extension Permissions

  • activeTab, scripting & content_scripts: Used solely when you explicitly activate the element picker (toolbar click or Alt+Shift+G) to highlight elements, read local computed styles (getComputedStyle), fetch public page stylesheets with credentials: 'omit' for hover class synthesis, and distill the selected DOM subtree in browser memory.
  • clipboardWrite: Used only when you click a target element in picker mode or click a Copy button in the extension UI to place the distilled prompt or code onto your local clipboard.
  • storage (chrome.storage.local): Stores your UI preferences (language, output format, token budget) and up to 20 recent grabs locally on your own device. You can wipe all stored history anytime via the Clear button in the popup or by uninstalling the extension.

3. Third-Party Sharing & Limited Use Compliance

AnyGrab runs without remote servers or external LLM API calls. No user data is ever transferred to third parties, used for advertising, or used to determine creditworthiness. The use of information received from Google/Chrome APIs strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

4. Open Source & Contact

Full source code is publicly auditable at https://github.com/botshen/anygrab. For questions, open an issue at github.com/botshen/anygrab/issues.

简体中文 — 隐私政策

1. 零数据收集与纯本地运行承诺

AnyGrab 是一款遵循 MIT 开源协议、100% 在本地浏览器运行的网页 DOM 与 UI 上下文提纯工具。我们绝不收集、上传、在任何远程服务器存储、出售或向第三方共享您的个人信息、浏览历史、网页内容、Cookie、账号凭证或使用统计数据。

2. 浏览器扩展权限用途说明

  • activeTab、scripting 与 content_scripts：仅当您主动点击扩展图标或按下快捷键 Alt+Shift+G 启动光学取景器时，用于在页面本地渲染 Shadow-DOM 选框、读取所选元素的计算样式（getComputedStyle），并在不携带任何身份凭证（credentials: 'omit'）的前提下读取页面引用的公开样式表以还原 :hover 交互类名。所有处理均在本地内存中完成。
  • clipboardWrite（剪贴板写入）：仅当您点选网页目标元素或点击扩展面板内的「复制」按钮时，将提纯后的 AI Prompt、React JSX、Tailwind HTML 或 Markdown 写入本机剪贴板。
  • storage（chrome.storage.local）：仅在您的设备本地保存语言、输出格式、Token 预算等偏好设置及最近最多 20 条本地提取记录。您可随时通过弹窗内的「清空」按钮或卸载扩展彻底删除所有本地数据。

3. 第三方共享与合规声明

AnyGrab 不依赖任何后端服务器，不调用任何外部大模型接口，绝不会向任何第三方传输用户数据，严格遵守 Chrome Web Store 用户数据政策（包括有限使用要求）。

4. 开源透明与联系方式

完整源码公开在 GitHub：https://github.com/botshen/anygrab。如有任何隐私与安全问题，请访问 GitHub Issues 反馈。
